Production
==========

The following production tutorials are available:

* :doc:`A. Choose the (potential) heat sources and compose a source mix <../step_by_step/production/production_step_a>`

  Design Toolkit is demand-driven. Only after heating demand has been defined, we define
  the source mix. We do so for a baseline design; the source mix can consist of a single
  source or multiple sources, and of existing and/or potential sources.

  In this Step by step, we define a source mix consisting of a geothermal source and a
  gas-heated boiler (both existing)

* :doc:`B. Account for changes in the source mix towards 2050 <../step_by_step/production/production_step_b>`

  The source mix will change during the heating transition, as existing sources may be
  outphased and new (potential) sources become part of the source mix.

  These changes over time are effectuated with the scenario manager.

  In this Step by step, we look into future scenarios of changing commodity prices and
  new potential sources

* :doc:`C. Security of supply <../step_by_step/production/production_step_c>`

  Providing security of supply becomes more challenging when sudden unavailability of
  sources is taken into account. This can be caused by technical issues (failure) but
  also by geopolitical threats (sabotage, warfare).

  We can assess how resilient a system design is against these events by comparing
  design variations in the source mix, by number, location and properties
