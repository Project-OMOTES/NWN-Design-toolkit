Production Step C: Security of supply
=====================================

Providing security of supply becomes more challenging when sudden unavailability of
sources is taken into account. This can be caused by technical issues (failure) but also
by geopolitical threats (sabotage, warfare).

We can assess how resilient a system design is against these events by comparing design
variations in the source mix, by number, location and properties

1. Create/update the baseline ESDL


   * Example 1: Failing geothermal source


      * Define variant - ESDL file that excludes the geothermal source from the baseline
        ESDL and includes extra gas-heated boilers to each of several collective heating
        demand clusters.


   * Example 2: Pipeline from waste heat source destroyed


      * Define variant - ESDL file that excludes the pipeline from the (central) waste
        heat source from the baseline ESDL and includes extra gas-heated boilers to each
        of several collective heating demand clusters.
